# VS Code

My VS Code configuration and extensions.

## Contents

| File            | Description                                         |
| --------------- | --------------------------------------------------- |
| `settings.json` | VS Code user settings                               |
| `extensions.md` | List of installed extensions |

## Setup

Path of the `settings.json` file :

```text
~/.config/Code/User/settings.json
```

Install the extensions listed in `extensions.md` from the VS Code Marketplace.
